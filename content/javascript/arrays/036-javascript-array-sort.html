JavaScript · Arrays

1. Apa itu JavaScript Array Sort?

Array adalah struktur data yang menyimpan banyak nilai dalam satu variabel. Index dimulai dari 0.

2. Konsep yang perlu kamu kuasai

  • Akses item dengan index.
  • push menambah item.
  • map membuat array baru dari hasil transformasi.
  • filter memilih item yang memenuhi kondisi.

3. Sintaks / contoh dasar

const nilai = [80, 90, 75];
console.log(nilai[0]);
const lulus = nilai.filter(n => n >= 80);
Perhatikan: Latihan array akan menjadi fondasi penting saat membuat daftar data atau aplikasi sekolah.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.
