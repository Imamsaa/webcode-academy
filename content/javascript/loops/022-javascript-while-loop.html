JavaScript · Loops

1. Apa itu JavaScript While Loop?

while menjalankan blok selama kondisi masih true.

2. Konsep yang perlu kamu kuasai

  • Kondisi diperiksa sebelum setiap putaran pada while.
  • Pastikan sesuatu di dalam loop dapat mengubah kondisi agar loop berhenti.
  • break dapat digunakan untuk keluar lebih awal.

3. Sintaks / contoh dasar

let i = 1;
while (i <= 5) {
  console.log(i);
  i++;
}
Perhatikan: Kesalahan umum adalah membuat infinite loop dengan kondisi yang tidak pernah false.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: while pada materi JavaScript While Loop.
  2. Kerjakan poin: condition/break pada materi JavaScript While Loop.
  3. Kerjakan poin: body pada materi JavaScript While Loop.
  4. Gabungkan JavaScript While Loop dengan kode lain dan buat hasil yang dapat dijalankan.
