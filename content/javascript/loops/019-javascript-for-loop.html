JavaScript · Loops

1. Apa itu JavaScript For Loop?

for loop menjalankan blok kode berulang kali dengan nilai awal, kondisi, dan perubahan yang jelas.

2. Konsep yang perlu kamu kuasai

  • Initialization menentukan nilai awal.
  • Condition menentukan kapan loop berhenti.
  • Increment mengubah nilai setiap putaran.

3. Sintaks / contoh dasar

for (let i = 1; i <= 5; i++) {
  console.log(i);
}
Perhatikan: Pastikan kondisi akhirnya menjadi false agar tidak terjadi infinite loop.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: for pada materi JavaScript For Loop.
  2. Kerjakan poin: increment pada materi JavaScript For Loop.
  3. Kerjakan poin: body pada materi JavaScript For Loop.
  4. Gabungkan JavaScript For Loop dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
