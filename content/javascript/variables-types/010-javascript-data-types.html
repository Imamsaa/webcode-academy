JavaScript · Variables & Types

1. Apa itu JavaScript Data Types?

JavaScript memiliki tipe data seperti string, number, boolean, null, undefined, object, dan bigint.

2. Konsep yang perlu kamu kuasai

  • String menyimpan teks.
  • Number menyimpan angka.
  • Boolean menyimpan true atau false.

3. Sintaks / contoh dasar

const nama = "Budi";
const umur = 13;
const aktif = true;
Perhatikan: Tipe data memengaruhi operasi yang dapat dilakukan dan hasil program.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: value pada materi JavaScript Data Types.
  2. Kerjakan poin: typeof pada materi JavaScript Data Types.
  3. Kerjakan poin: boolean pada materi JavaScript Data Types.
  4. Gabungkan JavaScript Data Types dengan kode lain dan buat hasil yang dapat dijalankan.
