JavaScript · Variables & Types

1. Apa itu JavaScript Variables?

Variabel adalah nama yang kita gunakan untuk menyimpan nilai. Dalam JavaScript modern, gunakan let ketika nilai dapat berubah dan const ketika binding tidak diganti.

2. Konsep yang perlu kamu kuasai

  • let dapat diberi nilai baru.
  • const tidak dapat di-assign ulang.
  • var adalah sintaks lama dengan aturan scope berbeda.

3. Sintaks / contoh dasar

let skor = 0;
skor = skor + 10;
const nama = "Rani";
console.log(skor, nama);
Perhatikan: Nama seperti skor, namaSiswa, atau totalNilai lebih mudah dipahami daripada nama seperti x1 dan a2.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: let/const pada materi JavaScript Variables.
  2. Kerjakan poin: assignment pada materi JavaScript Variables.
  3. Kerjakan poin: read variable pada materi JavaScript Variables.
  4. Gabungkan JavaScript Variables dengan kode lain dan buat hasil yang dapat dijalankan.
