JavaScript · Functions

1. Apa itu JavaScript Arrow Function?

Function adalah blok kode yang dapat dipanggil kembali. Function dapat menerima parameter dan mengembalikan hasil dengan return.

2. Konsep yang perlu kamu kuasai

  • Function menghindari pengulangan kode.
  • Parameter adalah input function.
  • return mengirim nilai keluar dari function.

3. Sintaks / contoh dasar

function tambah(a, b) {
  return a + b;
}

const hasil = tambah(3, 4);
console.log(hasil);
Perhatikan: Buat function kecil dengan satu tujuan yang jelas agar mudah diuji dan dipakai ulang.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.
