JavaScript · Objects

1. Apa itu JavaScript Object Methods?

Object menyimpan data dalam pasangan property dan value.

2. Konsep yang perlu kamu kuasai

  • Property dapat diakses dengan dot atau bracket notation.
  • Object dapat memiliki method.
  • Object cocok untuk menggambarkan satu entitas.

3. Sintaks / contoh dasar

const siswa = { nama: "Alya", umur: 13 };
console.log(siswa.nama);
Perhatikan: Gunakan object untuk data yang saling menggambarkan satu benda atau entitas.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.
