JavaScript · Strings

1. Apa itu JavaScript Strings?

String menyimpan teks. JavaScript menyediakan banyak method untuk membaca, mencari, memotong, dan mengubah string.

2. Konsep yang perlu kamu kuasai

  • String dapat dibuat dengan kutip tunggal, ganda, atau backtick.
  • length membaca jumlah karakter.
  • Method seperti includes, slice, trim, toUpperCase, dan toLowerCase sering digunakan.

3. Sintaks / contoh dasar

const nama = "Alya";
console.log(nama.toUpperCase());
console.log(nama.length);
Perhatikan: String method biasanya mengembalikan string baru; jangan berasumsi nilai asli berubah.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: string pada materi JavaScript Strings.
  2. Kerjakan poin: method pada materi JavaScript Strings.
  3. Kerjakan poin: length pada materi JavaScript Strings.
  4. Gabungkan JavaScript Strings dengan kode lain dan buat hasil yang dapat dijalankan.
