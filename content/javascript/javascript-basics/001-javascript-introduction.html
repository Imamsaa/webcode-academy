JavaScript · JavaScript Basics

1. Apa itu JavaScript Introduction?

JavaScript adalah bahasa pemrograman yang memberi perilaku pada halaman web. JavaScript dapat menghitung, mengambil keputusan, mengelola data, menangani event, dan mengubah DOM.

2. Konsep yang perlu kamu kuasai

  • HTML menyusun struktur, CSS mengatur tampilan, JavaScript menambahkan perilaku.
  • JavaScript dapat dijalankan di browser.
  • console.log membantu melihat hasil saat belajar.

3. Sintaks / contoh dasar

const nama = "Alya";
console.log("Halo, " + nama);
Perhatikan: Belajarlah secara bertahap: statement → variable → condition → loop → function → object/array → DOM → asynchronous.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: javascript code pada materi JavaScript Introduction.
  2. Kerjakan poin: console pada materi JavaScript Introduction.
  3. Kerjakan poin: statement pada materi JavaScript Introduction.
