JavaScript · Conditionals

1. Apa itu JavaScript If Else?

if dan else membuat program mengambil keputusan berdasarkan kondisi.

2. Konsep yang perlu kamu kuasai

  • if berjalan ketika kondisi true.
  • else berjalan ketika kondisi false.
  • else if dapat dipakai untuk lebih dari dua kondisi.

3. Sintaks / contoh dasar

const nilai = 85;
if (nilai >= 80) {
  console.log("Lulus");
} else {
  console.log("Belajar lagi");
}
Perhatikan: Tuliskan kondisi dengan jelas agar alur program mudah dibaca.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: if pada materi JavaScript If Else.
  2. Kerjakan poin: else pada materi JavaScript If Else.
  3. Kerjakan poin: condition pada materi JavaScript If Else.
  4. Gabungkan JavaScript If Else dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
