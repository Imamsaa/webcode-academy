JavaScript · Async

1. Apa itu JavaScript Async Await?

async/await membuat alur asynchronous lebih mudah dibaca.

2. Konsep yang perlu kamu kuasai

  • async membuat function mengembalikan Promise.
  • await menunggu Promise selesai di dalam async function.
  • try/catch dapat dipakai untuk error handling.

3. Sintaks / contoh dasar

async function ambilData() {
  const response = await fetch("data.json");
  const data = await response.json();
  console.log(data);
}
Perhatikan: Gunakan async/await saat beberapa langkah asynchronous perlu dibaca berurutan.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.
