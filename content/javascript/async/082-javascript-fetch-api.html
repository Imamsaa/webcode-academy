JavaScript · Async

1. Apa itu JavaScript Fetch API?

Fetch API digunakan untuk berkomunikasi dengan resource melalui HTTP. Di browser, fetch sering digunakan untuk mengambil JSON dari API.

2. Konsep yang perlu kamu kuasai

  • fetch mengembalikan Promise.
  • response.json() mengubah body JSON menjadi object JavaScript.
  • Tangani error dengan catch atau try/catch saat memakai async/await.

3. Sintaks / contoh dasar

fetch("data.json")
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error(error));
Perhatikan: Di GitHub Pages, fetch dapat digunakan untuk file JSON statis dan API publik yang mengizinkan akses dari browser.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: fetch pada materi JavaScript Fetch API.
  2. Kerjakan poin: json pada materi JavaScript Fetch API.
  3. Kerjakan poin: then/await pada materi JavaScript Fetch API.
  4. Gabungkan JavaScript Fetch API dengan kode lain dan buat hasil yang dapat dijalankan.
