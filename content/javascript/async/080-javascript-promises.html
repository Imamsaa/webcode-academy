JavaScript · Async

1. Apa itu JavaScript Promises?

Promise mewakili hasil pekerjaan asynchronous yang belum selesai, selesai, atau gagal.

2. Konsep yang perlu kamu kuasai

  • then menangani hasil sukses.
  • catch menangani kegagalan.
  • finally dapat dipakai untuk pekerjaan yang selalu dijalankan setelah selesai.

3. Sintaks / contoh dasar

const tugas = new Promise(resolve => {
  setTimeout(() => resolve("Selesai"), 500);
});
tugas.then(console.log);
Perhatikan: Promise menjadi dasar dari banyak API browser modern termasuk fetch.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: promise pada materi JavaScript Promises.
  2. Kerjakan poin: then pada materi JavaScript Promises.
  3. Kerjakan poin: catch pada materi JavaScript Promises.
  4. Gabungkan JavaScript Promises dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
