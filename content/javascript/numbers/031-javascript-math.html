JavaScript · Numbers

1. Apa itu JavaScript Math?

Objek Math menyediakan fungsi matematika seperti round, floor, ceil, abs, max, min, dan random.

2. Konsep yang perlu kamu kuasai

  • Math.round membulatkan ke terdekat.
  • Math.floor membulatkan ke bawah.
  • Math.random menghasilkan angka desimal 0 sampai kurang dari 1.

3. Sintaks / contoh dasar

const angka = Math.random() * 10;
console.log(Math.floor(angka));
Perhatikan: Gabungkan Math.random dan Math.floor untuk membuat angka acak bulat.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.
