JavaScript · Numbers

1. Apa itu JavaScript Random?

Math.random() menghasilkan angka pseudo-random dari 0 (inklusif) sampai kurang dari 1 (eksklusif).

2. Konsep yang perlu kamu kuasai

  • Math.random() menghasilkan 0 <= x < 1.
  • Math.floor dapat mengubahnya menjadi integer.
  • Kalikan dengan range sebelum dibulatkan.

3. Sintaks / contoh dasar

const dadu = Math.floor(Math.random() * 6) + 1;
console.log(dadu);
Perhatikan: Rumus ini menghasilkan angka 1-6, cocok untuk simulasi dadu sederhana.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.
