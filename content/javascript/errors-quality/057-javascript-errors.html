JavaScript · Errors & Quality

1. Apa itu JavaScript Errors?

JavaScript Errors adalah konsep JavaScript yang dipelajari setelah dasar program mulai dikuasai.

2. Konsep yang perlu kamu kuasai

  • Pahami tujuan JavaScript Errors.
  • Kenali sintaks dan istilah yang digunakan.
  • Gunakan console.log untuk mengamati hasil.
  • Gabungkan dengan konsep sebelumnya setelah contoh dasar berjalan.

3. Sintaks / contoh dasar

// JavaScript Errors
const message = "Mulai latihan JavaScript Errors";
console.log(message);
Perhatikan: Bacalah error di Console saat latihan. Error adalah petunjuk, bukan akhir dari proses belajar.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: try pada materi JavaScript Errors.
  2. Kerjakan poin: catch pada materi JavaScript Errors.
  3. Kerjakan poin: throw/error pada materi JavaScript Errors.
  4. Gabungkan JavaScript Errors dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
