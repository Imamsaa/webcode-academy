JavaScript · DOM & Events

1. Apa itu JavaScript DOM Changing CSS?

DOM adalah representasi dokumen HTML yang dapat dipilih dan diubah oleh JavaScript.

2. Konsep yang perlu kamu kuasai

  • document adalah pintu masuk ke DOM.
  • querySelector memilih elemen.
  • textContent dan innerHTML dapat mengubah content.

3. Sintaks / contoh dasar

const judul = document.querySelector("h1");
judul.textContent = "Judul Baru";
Perhatikan: Jalankan kode di playground yang memiliki elemen h1 supaya perubahan terlihat.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

  3. Kerjakan poin: setattribute pada materi JavaScript DOM Changing CSS.
