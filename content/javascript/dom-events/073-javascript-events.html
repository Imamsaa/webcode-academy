JavaScript · DOM & Events

1. Apa itu JavaScript Events?

Event adalah kejadian yang dapat dideteksi JavaScript, misalnya click, input, submit, keydown, atau change.

2. Konsep yang perlu kamu kuasai

  • addEventListener memasang handler.
  • Handler adalah function yang dipanggil ketika event terjadi.
  • Event object bisa memberi informasi tentang kejadian.

3. Sintaks / contoh dasar

document.querySelector("button").addEventListener("click", () => {
  alert("Tombol diklik!");
});
Perhatikan: Event adalah dasar interaksi: tombol, form, keyboard, mouse, dan input dapat semuanya menjadi pemicu.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Kurung atau kurawal tidak berpasangan.
  • Nama variabel/function tidak konsisten.
  • Mengabaikan error di Console.

6. Latihan bertingkat

  1. Kerjakan poin: listener pada materi JavaScript Events.
  2. Kerjakan poin: event name pada materi JavaScript Events.
  3. Kerjakan poin: callback pada materi JavaScript Events.
  4. Gabungkan JavaScript Events dengan kode lain dan buat hasil yang dapat dijalankan.
