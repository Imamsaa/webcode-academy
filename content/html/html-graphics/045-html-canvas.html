1. Apa itu HTML Canvas?

HTML Canvas adalah bagian dari HTML yang perlu dipahami lewat struktur, contoh, dan latihan langsung. Fokuskan pembelajaran pada kapan fitur ini dipakai, bentuk sintaksnya, dan kesalahan yang sering terjadi.

2. Konsep yang perlu kamu kuasai

  • Pahami tujuan utama HTML Canvas.
  • Kenali sintaks dan bagian-bagian pentingnya.
  • Coba ubah contoh satu bagian demi satu bagian.
  • Gabungkan dengan elemen HTML sebelumnya.

3. Sintaks / contoh dasar

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>HTML Canvas</title>
</head>
<body>
  <h1>HTML Canvas</h1>
  <p>Ubah contoh ini.</p>
</body>
</html>
Perhatikan: Jangan hanya menghafal. Ubah contoh, lihat hasilnya, lalu jelaskan kembali dengan kata-kata sendiri.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: canvas pada materi HTML Canvas.
  2. Kerjakan poin: id pada materi HTML Canvas.
  3. Kerjakan poin: drawing script pada materi HTML Canvas.
  4. Gabungkan HTML Canvas dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
