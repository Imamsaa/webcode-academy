HTML · HTML Forms

1. Apa itu HTML Forms?

Form menampung input dari pengguna. Elemen yang sering dipakai adalah form, label, input, select, textarea, dan button.

2. Konsep yang perlu kamu kuasai

  • label membantu pengguna memahami input.
  • name menjadi nama data saat form dikirim.
  • type menentukan jenis input.

3. Sintaks / contoh dasar

<form>
  <label for="nama">Nama:</label>
  <input id="nama" name="nama" type="text">
  <button type="submit">Kirim</button>
</form>
Perhatikan: Di GitHub Pages tanpa backend, form dapat digunakan untuk belajar antarmuka dan validasi di browser, tetapi belum mengirim data ke server sekolah.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: form pada materi HTML Forms.
  2. Kerjakan poin: input pada materi HTML Forms.
  3. Kerjakan poin: label/name pada materi HTML Forms.
  4. Gabungkan HTML Forms dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
