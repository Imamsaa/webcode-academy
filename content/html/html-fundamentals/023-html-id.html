HTML · HTML Fundamentals

1. Apa itu HTML Id?

Atribut id memberikan identitas unik pada sebuah elemen dalam dokumen.

2. Konsep yang perlu kamu kuasai

  • Satu id sebaiknya hanya dipakai pada satu elemen.
  • CSS dapat memilih id dengan #namaId.
  • JavaScript sering memilih id dengan getElementById.

3. Sintaks / contoh dasar

<h1 id="judul">Belajar HTML</h1>
Perhatikan: Gunakan class untuk grouping dan id untuk elemen yang benar-benar unik.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: id pada materi HTML Id.
  2. Kerjakan poin: id selector pada materi HTML Id.
  3. Kerjakan poin: element id pada materi HTML Id.
  4. Gabungkan HTML Id dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
