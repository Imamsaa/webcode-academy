HTML · HTML Fundamentals

1. Apa itu HTML Symbols?

HTML Symbols membantu browser merepresentasikan karakter atau simbol dengan aturan yang tepat.

2. Konsep yang perlu kamu kuasai

  • Karakter tertentu punya representasi entity.
  • Charset menentukan cara byte dibaca menjadi karakter.
  • Gunakan UTF-8 untuk bahasa modern dan karakter umum.

3. Sintaks / contoh dasar

<meta charset="UTF-8">
<p>&copy; 2026 ICT Al Firdaus 🚀</p>
Perhatikan: Pastikan encoding file dan charset HTML selaras agar tulisan tidak menjadi karakter aneh.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: elemen/konsep pada materi HTML Symbols.
  2. Kerjakan poin: struktur pada materi HTML Symbols.
  3. Kerjakan poin: gabungkan pada materi HTML Symbols.
  4. Gabungkan HTML Symbols dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
