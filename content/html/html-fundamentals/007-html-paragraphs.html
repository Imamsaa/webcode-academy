HTML · HTML Fundamentals

1. Apa itu HTML Paragraphs?

Elemen <p> digunakan untuk paragraf. Browser memberi jarak antar paragraf secara otomatis sehingga tulisan lebih mudah dibaca.

2. Konsep yang perlu kamu kuasai

  • Gunakan <p> untuk blok teks.
  • Gunakan <br> hanya ketika benar-benar membutuhkan pindah baris.
  • Gunakan <pre> ketika spasi dan baris ingin dipertahankan.

3. Sintaks / contoh dasar

<p>Saya sedang belajar HTML.</p>
<p>Setiap gagasan dapat dibuat menjadi paragraf berbeda.</p>
<p>Baris satu<br>Baris dua</p>
Perhatikan: Hindari membuat satu paragraf raksasa hanya dengan banyak <br>. Struktur yang jelas membuat halaman lebih mudah dibaca.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: elemen/konsep pada materi HTML Paragraphs.
  2. Kerjakan poin: struktur pada materi HTML Paragraphs.
  3. Kerjakan poin: gabungkan pada materi HTML Paragraphs.
  4. Gabungkan HTML Paragraphs dengan kode lain dan buat hasil yang dapat dijalankan.
