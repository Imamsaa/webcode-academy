HTML · HTML Fundamentals

1. Apa itu HTML Formatting?

Elemen formatting memberi makna atau tampilan tertentu pada sebagian teks, misalnya strong, em, mark, small, del, ins, sub, dan sup.

2. Konsep yang perlu kamu kuasai

  • Gunakan elemen sesuai makna content.
  • strong/em lebih semantik daripada sekadar membuat teks bold/italic dengan CSS.
  • Jangan gunakan formatting hanya untuk mengatur layout.

3. Sintaks / contoh dasar

<p><strong>Penting</strong> dan <em>miring</em>.</p>
Perhatikan: Bedakan formatting semantik dan styling CSS.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: elemen/konsep pada materi HTML Formatting.
  2. Kerjakan poin: struktur pada materi HTML Formatting.
  3. Kerjakan poin: gabungkan pada materi HTML Formatting.
  4. Gabungkan HTML Formatting dengan kode lain dan buat hasil yang dapat dijalankan.
