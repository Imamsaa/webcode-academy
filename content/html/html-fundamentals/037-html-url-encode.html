1. Apa itu HTML URL Encode?

URL encoding mengubah karakter tertentu menjadi format aman untuk bagian URL. Spasi biasanya di-encode agar tidak membingungkan parser URL.

2. Konsep yang perlu kamu kuasai

  • encodeURIComponent cocok untuk bagian nilai URL.
  • decodeURIComponent mengembalikan hasilnya.
  • Jangan encode seluruh URL secara sembarangan jika hanya satu parameter yang perlu di-encode.

3. Sintaks / contoh dasar

const q = encodeURIComponent("belajar HTML & CSS");
console.log(q);
Perhatikan: URL encoding biasanya ditemui saat membuat query parameter.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: elemen/konsep pada materi HTML URL Encode.
  2. Kerjakan poin: struktur pada materi HTML URL Encode.
  3. Kerjakan poin: gabungkan pada materi HTML URL Encode.
  4. Gabungkan HTML URL Encode dengan kode lain dan buat hasil yang dapat dijalankan.
