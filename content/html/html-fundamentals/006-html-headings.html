HTML · HTML Fundamentals

1. Apa itu HTML Headings?

Heading digunakan untuk membuat hierarki judul dari <h1> sampai <h6>. Ukuran visual bukan tujuan utama; yang penting adalah struktur informasi.

2. Konsep yang perlu kamu kuasai

  • h1 biasanya dipakai untuk judul utama halaman.
  • h2 dipakai untuk bagian utama.
  • h3-h6 dapat digunakan sebagai subbagian yang lebih dalam.

3. Sintaks / contoh dasar

<h1>Website Sekolah</h1>
<h2>Program Unggulan</h2>
<h3>ICT</h3>
Perhatikan: Bayangkan sebuah buku: h1 seperti judul buku, h2 seperti bab, h3 seperti subbab.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: elemen/konsep pada materi HTML Headings.
  2. Kerjakan poin: struktur pada materi HTML Headings.
  3. Kerjakan poin: gabungkan pada materi HTML Headings.
  4. Gabungkan HTML Headings dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
