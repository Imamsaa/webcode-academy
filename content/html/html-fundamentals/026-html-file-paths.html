HTML · HTML Fundamentals

1. Apa itu HTML File Paths?

File path menunjukkan lokasi file relatif terhadap halaman atau absolut dari sebuah alamat web.

2. Konsep yang perlu kamu kuasai

  • Path relatif seperti images/robot.jpg bergantung pada lokasi file HTML.
  • ../ berarti naik satu folder.
  • Path yang konsisten penting di GitHub Pages.

3. Sintaks / contoh dasar

<img src="images/robot.jpg" alt="Robot">
Perhatikan: Buat struktur folder sederhana agar path mudah dipahami siswa.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: elemen/konsep pada materi HTML File Paths.
  2. Kerjakan poin: struktur pada materi HTML File Paths.
  3. Kerjakan poin: gabungkan pada materi HTML File Paths.
  4. Gabungkan HTML File Paths dengan kode lain dan buat hasil yang dapat dijalankan.
