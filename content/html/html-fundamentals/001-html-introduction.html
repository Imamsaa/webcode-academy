HTML · HTML Fundamentals

1. Apa itu HTML Introduction?

HTML (HyperText Markup Language) adalah bahasa markup untuk menyusun struktur halaman web. Browser membaca dokumen HTML lalu mengetahui bagian mana yang merupakan judul, paragraf, gambar, link, tabel, formulir, dan bagian lainnya.

2. Konsep yang perlu kamu kuasai

  • HTML bukan bahasa pemrograman untuk menghitung logika seperti JavaScript; HTML memberi struktur.
  • Dokumen HTML biasanya memiliki <!DOCTYPE html>, <html>, <head>, dan <body>.
  • Elemen seperti <h1> dan <p> memberi makna pada content.

3. Sintaks / contoh dasar

<!DOCTYPE html>
<html>
<head>
  <title>Halaman Saya</title>
</head>
<body>
  <h1>Halo Dunia!</h1>
  <p>Saya sedang belajar HTML.</p>
</body>
</html>
Perhatikan: Urutan dan struktur penting. Bayangkan HTML sebagai kerangka rumah: sebelum memperindah rumah, bangun kerangkanya terlebih dahulu.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: doctype pada materi HTML Introduction.
  2. Kerjakan poin: heading pada materi HTML Introduction.
  3. Kerjakan poin: paragraph pada materi HTML Introduction.
  4. Gabungkan HTML Introduction dengan kode lain dan buat hasil yang dapat dijalankan.
