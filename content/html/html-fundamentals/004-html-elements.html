HTML · HTML Fundamentals

1. Apa itu HTML Elements?

Elemen HTML adalah bagian utuh dari dokumen. Elemen yang memiliki content biasanya terdiri dari tag pembuka, content, dan tag penutup. Ada juga empty element seperti <br> dan <img> yang tidak memiliki tag penutup.

2. Konsep yang perlu kamu kuasai

  • Tag pembuka menandai awal elemen.
  • Content berada di antara tag untuk elemen yang memiliki isi.
  • Tag penutup ditulis dengan tanda / pada elemen yang membutuhkannya.

3. Sintaks / contoh dasar

<h1>Judul</h1>
<p>Ini sebuah paragraf.</p>
<br>
<img src="robot.jpg" alt="Robot">
Perhatikan: Jangan menghafal tag tanpa memahami maknanya. Tanyakan: “Apa yang ingin saya nyatakan di halaman?” lalu pilih elemen yang tepat.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: elemen/konsep pada materi HTML Elements.
  2. Kerjakan poin: struktur pada materi HTML Elements.
  3. Kerjakan poin: gabungkan pada materi HTML Elements.
  4. Gabungkan HTML Elements dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
