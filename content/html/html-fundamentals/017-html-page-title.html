HTML · HTML Fundamentals

1. Apa itu HTML Page Title?

Bagian head menyimpan metadata dan resource yang membantu browser memahami halaman. Salah satu isinya adalah title yang tampil di tab browser.

2. Konsep yang perlu kamu kuasai

  • title ditulis di head.
  • meta charset membantu pengkodean teks.
  • link dapat menghubungkan CSS, favicon, dan resource lain.

3. Sintaks / contoh dasar

<head>
  <meta charset="UTF-8">
  <title>Website Saya</title>
  <link rel="stylesheet" href="style.css">
</head>
Perhatikan: Content visual utama ada di body, sedangkan informasi tentang dokumen banyak berada di head.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: elemen/konsep pada materi HTML Page Title.
  2. Kerjakan poin: struktur pada materi HTML Page Title.
  3. Kerjakan poin: gabungkan pada materi HTML Page Title.
  4. Gabungkan HTML Page Title dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
