HTML · HTML Fundamentals

1. Apa itu HTML Images?

Elemen <img> digunakan untuk menampilkan gambar. Atribut src menunjuk file dan alt memberi teks alternatif.

2. Konsep yang perlu kamu kuasai

  • img adalah empty element.
  • src wajib menunjuk sumber gambar yang benar.
  • alt penting untuk accessibility dan ketika gambar gagal dimuat.

3. Sintaks / contoh dasar

<img src="robot.jpg" alt="Robot belajar coding" width="320" height="200">
Perhatikan: Nama file, folder, dan ekstensi harus tepat. Di GitHub Pages, perhatikan huruf besar-kecil pada nama file.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: img pada materi HTML Images.
  2. Kerjakan poin: src pada materi HTML Images.
  3. Kerjakan poin: alt pada materi HTML Images.
  4. Gabungkan HTML Images dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
