HTML · HTML Fundamentals

1. Apa itu HTML Links?

Link atau hyperlink dibuat dengan elemen <a>. Atribut href menentukan halaman, file, atau alamat yang akan dituju.

2. Konsep yang perlu kamu kuasai

  • <a> membuat anchor.
  • href menentukan tujuan.
  • Teks link sebaiknya menjelaskan tujuan link.

3. Sintaks / contoh dasar

<a href="https://www.w3schools.com">Belajar HTML</a>
<a href="about.html">Tentang Saya</a>
Perhatikan: URL lengkap dimulai seperti https://..., sedangkan file dalam project bisa memakai path relatif seperti about.html.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: anchor tag pada materi HTML Links.
  2. Kerjakan poin: href pada materi HTML Links.
  3. Kerjakan poin: closing anchor pada materi HTML Links.
  4. Gabungkan HTML Links dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
