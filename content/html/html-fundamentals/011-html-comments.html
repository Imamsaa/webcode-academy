HTML · HTML Fundamentals

1. Apa itu HTML Comments?

Komentar adalah catatan di source code yang tidak ditampilkan sebagai content halaman.

2. Konsep yang perlu kamu kuasai

  • Mulai dengan <!-- dan akhiri -->.
  • Komentar dapat membantu menjelaskan bagian kode.
  • Jangan menaruh password atau data sensitif di komentar.

3. Sintaks / contoh dasar

<!-- Menu utama -->
<nav>...</nav>
Perhatikan: Komentar berguna untuk manusia, bukan untuk memberi perintah kepada browser.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: elemen/konsep pada materi HTML Comments.
  2. Kerjakan poin: struktur pada materi HTML Comments.
  3. Kerjakan poin: gabungkan pada materi HTML Comments.
  4. Gabungkan HTML Comments dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
