HTML · HTML Fundamentals

1. Apa itu HTML Tables?

Table digunakan untuk data yang memang berbentuk baris dan kolom, seperti daftar nilai, jadwal, atau tabel perbandingan.

2. Konsep yang perlu kamu kuasai

  • table membungkus tabel.
  • tr membuat baris.
  • th membuat header dan td membuat sel data.

3. Sintaks / contoh dasar

<table>
  <tr><th>Nama</th><th>Nilai</th></tr>
  <tr><td>Ani</td><td>90</td></tr>
</table>
Perhatikan: Jangan memakai tabel untuk membuat layout website. Gunakan Flexbox/Grid untuk layout.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: table pada materi HTML Tables.
  2. Kerjakan poin: row pada materi HTML Tables.
  3. Kerjakan poin: cell pada materi HTML Tables.
  4. Gabungkan HTML Tables dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
