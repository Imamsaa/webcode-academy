1. Apa itu HTML Favicon?

Favicon adalah icon kecil yang muncul pada tab browser dan bookmark.

2. Konsep yang perlu kamu kuasai

  • Gunakan elemen link di head.
  • href menunjuk file icon.
  • Rel biasanya icon.

3. Sintaks / contoh dasar

<link rel="icon" href="favicon.png">
Perhatikan: Favicon berada di head karena merupakan metadata halaman.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: elemen/konsep pada materi HTML Favicon.
  2. Kerjakan poin: struktur pada materi HTML Favicon.
  3. Kerjakan poin: gabungkan pada materi HTML Favicon.
  4. Gabungkan HTML Favicon dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
