HTML · HTML Fundamentals

1. Apa itu HTML Lists?

List digunakan untuk menampilkan daftar item. <ul> digunakan untuk daftar tanpa urutan, <ol> untuk urutan, dan <li> untuk item.

2. Konsep yang perlu kamu kuasai

  • ul = unordered list.
  • ol = ordered list.
  • li = list item.
  • List dapat dibuat bertingkat (nested).

3. Sintaks / contoh dasar

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>
<ol>
  <li>Belajar</li>
  <li>Latihan</li>
</ol>
Perhatikan: Pilih ul atau ol berdasarkan makna data, bukan berdasarkan bentuk bullet/angka yang terlihat.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: ul/ol pada materi HTML Lists.
  2. Kerjakan poin: li pada materi HTML Lists.
  3. Kerjakan poin: nested list pada materi HTML Lists.
  4. Gabungkan HTML Lists dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
