HTML · HTML Fundamentals

1. Apa itu HTML Attributes?

Atribut menambahkan informasi atau kemampuan pada sebuah elemen. Atribut ditulis di tag pembuka dan biasanya menggunakan format name="value".

2. Konsep yang perlu kamu kuasai

  • Atribut berada di tag pembuka.
  • Nilai atribut sebaiknya diberi tanda kutip ganda.
  • Tidak semua atribut berlaku untuk semua elemen.

3. Sintaks / contoh dasar

<a href="https://example.com" title="Buka situs">Kunjungi</a>
<img src="robot.jpg" alt="Robot belajar" width="300">
Perhatikan: Pada contoh, href menentukan tujuan link, title memberi informasi tambahan, src menentukan sumber gambar, dan alt menjadi teks alternatif.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

  3. Kerjakan poin: useful attribute pada materi HTML Attributes.
