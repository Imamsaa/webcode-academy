HTML · HTML Fundamentals

1. Apa itu HTML Classes?

Atribut class memberi satu atau beberapa nama kelompok pada elemen. Class sangat sering digunakan untuk CSS dan JavaScript.

2. Konsep yang perlu kamu kuasai

  • Satu elemen dapat memiliki beberapa class.
  • Banyak elemen boleh memakai class yang sama.
  • CSS class selector menggunakan titik.

3. Sintaks / contoh dasar

<p class="info penting">Teks</p>
<style>.info { color: navy; }</style>
Perhatikan: Gunakan nama class yang menggambarkan peran, bukan tampilan sesaat.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: class pada materi HTML Classes.
  2. Kerjakan poin: selector pada materi HTML Classes.
  3. Kerjakan poin: class element pada materi HTML Classes.
  4. Gabungkan HTML Classes dengan kode lain dan buat hasil yang dapat dijalankan.
