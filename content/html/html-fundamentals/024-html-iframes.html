HTML · HTML Fundamentals

1. Apa itu HTML Iframes?

iframe menanam halaman atau resource lain ke dalam halaman kita.

2. Konsep yang perlu kamu kuasai

  • src menentukan resource yang ditampilkan.
  • width/height mengatur ukuran area.
  • Pastikan resource target mengizinkan ditampilkan lewat iframe.

3. Sintaks / contoh dasar

<iframe src="https://example.com" title="Contoh"></iframe>
Perhatikan: Iframe berguna untuk embedding, tetapi ada batasan keamanan dan kebijakan browser.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: iframe pada materi HTML Iframes.
  2. Kerjakan poin: src pada materi HTML Iframes.
  3. Kerjakan poin: dimensions pada materi HTML Iframes.
  4. Gabungkan HTML Iframes dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
