HTML · HTML Fundamentals

1. Apa itu HTML Div?

div adalah container generik untuk mengelompokkan content. Div tidak memberi makna semantik khusus, sehingga sering dipakai bersama class atau id.

2. Konsep yang perlu kamu kuasai

  • div cocok untuk grouping.
  • Gunakan class/id agar kelompok bisa ditargetkan CSS/JS.
  • Jika tersedia elemen semantic yang tepat, pertimbangkan menggunakannya.

3. Sintaks / contoh dasar

<div class="card">
  <h2>Judul</h2>
  <p>Isi card.</p>
</div>
Perhatikan: div adalah alat pengelompokan, bukan pengganti semua elemen HTML.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Tag pembuka dan penutup tidak seimbang.
  • Atribut ditempatkan bukan di tag pembuka.
  • Menggunakan elemen hanya karena tampilannya, bukan karena maknanya.

6. Latihan bertingkat

  1. Kerjakan poin: div pada materi HTML Div.
  2. Kerjakan poin: closing div pada materi HTML Div.
  3. Kerjakan poin: class pada materi HTML Div.
  4. Gabungkan HTML Div dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
