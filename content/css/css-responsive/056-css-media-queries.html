CSS · CSS Responsive

1. Apa itu CSS Media Queries?

Media query memungkinkan style berubah sesuai kondisi seperti lebar viewport.

2. Konsep yang perlu kamu kuasai

  • @media berisi aturan conditional.
  • max-width cocok untuk pendekatan mobile-first atau breakpoint tertentu.
  • Uji beberapa ukuran layar.

3. Sintaks / contoh dasar

@media (max-width: 700px) {
  .card { width: 100%; }
}
Perhatikan: Breakpoint bukan angka sakti. Pilih berdasarkan kapan layout mulai tidak nyaman.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: media pada materi CSS Media Queries.
  2. Kerjakan poin: breakpoint pada materi CSS Media Queries.
  3. Kerjakan poin: responsive property pada materi CSS Media Queries.
  4. Gabungkan CSS Media Queries dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
