CSS · CSS Responsive

1. Apa itu CSS Responsive Design?

Responsive design membuat halaman tetap nyaman pada desktop, laptop, tablet, dan HP.

2. Konsep yang perlu kamu kuasai

  • Gunakan unit relatif atau layout fleksibel.
  • Gunakan max-width agar content tidak terlalu lebar.
  • Gunakan media query untuk perubahan layout pada layar tertentu.

3. Sintaks / contoh dasar

@media (max-width: 700px) {
  .layout {
    grid-template-columns: 1fr;
  }
}
Perhatikan: Uji halaman dengan memperkecil lebar browser. Amati kapan layout perlu berubah dan mengapa.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: media query pada materi CSS Responsive Design.
  2. Kerjakan poin: breakpoint pada materi CSS Responsive Design.
  3. Kerjakan poin: fluid width pada materi CSS Responsive Design.
  4. Gabungkan CSS Responsive Design dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
