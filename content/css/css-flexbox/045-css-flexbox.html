CSS · CSS Flexbox

1. Apa itu CSS Flexbox?

Flexbox adalah sistem layout satu dimensi untuk menyusun item dalam baris atau kolom.

2. Konsep yang perlu kamu kuasai

  • display:flex mengubah parent menjadi flex container.
  • justify-content mengatur sumbu utama.
  • align-items mengatur sumbu silang.
  • gap memberi jarak antar item.

3. Sintaks / contoh dasar

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 16px;
}
Perhatikan: Mulailah dengan memahami parent dan child. Banyak property Flexbox bekerja pada container, sedangkan sebagian lainnya bekerja pada flex item.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: display flex pada materi CSS Flexbox.
  2. Kerjakan poin: justify/align pada materi CSS Flexbox.
  3. Kerjakan poin: flex property pada materi CSS Flexbox.
  4. Gabungkan CSS Flexbox dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
