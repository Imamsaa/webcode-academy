CSS · CSS Fundamentals

1. Apa itu CSS Margins?

Margin adalah ruang di luar border elemen. Margin dipakai untuk memberi jarak antar elemen.

2. Konsep yang perlu kamu kuasai

  • margin dapat ditulis satu nilai atau beberapa nilai.
  • margin-top/right/bottom/left mengatur sisi tertentu.
  • Margin collapse dapat terjadi pada block tertentu.

3. Sintaks / contoh dasar

.card { margin: 20px; }
Perhatikan: Bandingkan margin dengan padding: margin di luar, padding di dalam.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: margin pada materi CSS Margins.
  2. Kerjakan poin: margin-top pada materi CSS Margins.
  3. Kerjakan poin: horizontal margin pada materi CSS Margins.
  4. Gabungkan CSS Margins dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
