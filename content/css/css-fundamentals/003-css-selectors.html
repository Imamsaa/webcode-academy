CSS · CSS Fundamentals

1. Apa itu CSS Selectors?

Selector memilih elemen HTML yang akan diberi style. Selector dasar mencakup element, class, dan id.

2. Konsep yang perlu kamu kuasai

  • Element selector: p { }.
  • Class selector: .card { }.
  • ID selector: #judul { }.

3. Sintaks / contoh dasar

p { color: #333; }
.card { padding: 16px; }
#judul { color: navy; }
Perhatikan: Gunakan class untuk pola yang dapat digunakan berulang kali. ID biasanya digunakan untuk elemen yang unik.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: selector pada materi CSS Selectors.
  2. Kerjakan poin: class pada materi CSS Selectors.
  3. Kerjakan poin: id pada materi CSS Selectors.
  4. Gabungkan CSS Selectors dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
