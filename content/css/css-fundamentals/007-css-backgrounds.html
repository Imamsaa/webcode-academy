1. Apa itu CSS Backgrounds?

Background properties mengatur warna, gambar, pengulangan, posisi, ukuran, dan attachment background.

2. Konsep yang perlu kamu kuasai

  • background-color mengatur warna.
  • background-image dapat memakai url().
  • background-size mengatur ukuran gambar.

3. Sintaks / contoh dasar

.hero {
  background-color: #dff6ff;
  background-image: url("hero.jpg");
  background-size: cover;
}
Perhatikan: Coba ubah cover menjadi contain dan amati perbedaannya.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: background pada materi CSS Backgrounds.
  2. Kerjakan poin: url pada materi CSS Backgrounds.
  3. Kerjakan poin: size pada materi CSS Backgrounds.
  4. Gabungkan CSS Backgrounds dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
