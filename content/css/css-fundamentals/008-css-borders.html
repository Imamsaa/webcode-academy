CSS · CSS Fundamentals

1. Apa itu CSS Borders?

Border membingkai elemen. Anda dapat mengatur style, width, color, tiap sisi, dan radius sudut.

2. Konsep yang perlu kamu kuasai

  • border-style menentukan jenis garis.
  • border-width menentukan ketebalan.
  • border-radius membuat sudut membulat.

3. Sintaks / contoh dasar

.card {
  border: 2px solid #04aa6d;
  border-radius: 12px;
}
Perhatikan: Gunakan border untuk menonjolkan struktur komponen tanpa mengandalkan gambar.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: border pada materi CSS Borders.
  2. Kerjakan poin: radius pada materi CSS Borders.
  3. Kerjakan poin: border style pada materi CSS Borders.
  4. Gabungkan CSS Borders dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
