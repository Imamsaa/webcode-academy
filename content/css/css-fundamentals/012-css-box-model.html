CSS · CSS Fundamentals

1. Apa itu CSS Box Model?

Box model menjelaskan ruang sebuah elemen: content, padding, border, dan margin. Memahami ini membantu menjawab pertanyaan “mengapa kotak saya menjadi lebih besar?”

2. Konsep yang perlu kamu kuasai

  • Content adalah isi elemen.
  • Padding berada di dalam border.
  • Border mengelilingi padding/content.
  • Margin berada di luar border.

3. Sintaks / contoh dasar

.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #333;
  margin: 16px;
  box-sizing: border-box;
}
Perhatikan: box-sizing: border-box membuat width/height memasukkan padding dan border sehingga ukuran lebih mudah dikontrol.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: width pada materi CSS Box Model.
  2. Kerjakan poin: padding pada materi CSS Box Model.
  3. Kerjakan poin: border pada materi CSS Box Model.
  4. Gabungkan CSS Box Model dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
