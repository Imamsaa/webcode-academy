CSS · CSS Fundamentals

1. Apa itu CSS Fonts?

CSS font properties mengatur keluarga font, ukuran, ketebalan, style, dan banyak aspek tipografi lainnya.

2. Konsep yang perlu kamu kuasai

  • font-family memilih font.
  • font-size mengatur ukuran.
  • font-weight mengatur ketebalan.

3. Sintaks / contoh dasar

body {
  font-family: Arial, sans-serif;
}
h1 { font-size: 32px; font-weight: 800; }
Perhatikan: Gunakan fallback font agar teks tetap tampil jika font utama tidak tersedia.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: css rule pada materi CSS Fonts.
  2. Kerjakan poin: declaration pada materi CSS Fonts.
  3. Kerjakan poin: property/value pada materi CSS Fonts.
  4. Gabungkan CSS Fonts dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
