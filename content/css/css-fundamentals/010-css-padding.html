1. Apa itu CSS Padding?

Padding adalah ruang antara content dan border. Padding biasanya dipakai untuk membuat content tidak menempel pada tepi kotak.

2. Konsep yang perlu kamu kuasai

  • Padding berada di dalam border.
  • padding dapat diatur tiap sisi.
  • box-sizing memengaruhi perhitungan ukuran.

3. Sintaks / contoh dasar

.card { padding: 20px; }
Perhatikan: Padding memperbesar area dalam elemen ketika box-sizing default digunakan.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: padding pada materi CSS Padding.
  2. Kerjakan poin: padding-left pada materi CSS Padding.
  3. Kerjakan poin: horizontal padding pada materi CSS Padding.
  4. Gabungkan CSS Padding dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
