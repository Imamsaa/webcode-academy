CSS · CSS Fundamentals

1. Apa itu CSS Text?

CSS text properties mengatur warna, alignment, decoration, transform, spacing, shadow, dan aspek tipografi teks.

2. Konsep yang perlu kamu kuasai

  • color mengatur warna teks.
  • text-align mengatur alignment.
  • text-decoration mengatur garis/decoration.
  • line-height membantu kenyamanan membaca.

3. Sintaks / contoh dasar

p {
  color: #223;
  text-align: center;
  line-height: 1.6;
}
Perhatikan: Uji perubahan satu property sekali agar efeknya mudah dipahami.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: css rule pada materi CSS Text.
  2. Kerjakan poin: declaration pada materi CSS Text.
  3. Kerjakan poin: property/value pada materi CSS Text.
  4. Gabungkan CSS Text dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
