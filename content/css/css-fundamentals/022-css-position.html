CSS · CSS Fundamentals

1. Apa itu CSS Position?

Positioning menentukan bagaimana elemen ditempatkan dalam dokumen. Mode utama: static, relative, absolute, fixed, sticky.

2. Konsep yang perlu kamu kuasai

  • relative mempertahankan tempat asli tetapi dapat diberi offset.
  • absolute diposisikan relatif terhadap containing block tertentu.
  • fixed menempel pada viewport.
  • sticky dapat berpindah dari normal flow lalu menempel saat scroll.

3. Sintaks / contoh dasar

.box { position: relative; top: 10px; }
Perhatikan: Pahami normal flow sebelum memakai absolute/fixed secara berlebihan.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: position pada materi CSS Position.
  2. Kerjakan poin: position mode pada materi CSS Position.
  3. Kerjakan poin: offset pada materi CSS Position.
  4. Gabungkan CSS Position dengan kode lain dan buat hasil yang dapat dijalankan.
