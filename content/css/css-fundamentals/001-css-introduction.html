CSS · CSS Fundamentals

1. Apa itu CSS Introduction?

CSS (Cascading Style Sheets) digunakan untuk mengatur tampilan elemen HTML, misalnya warna, ukuran, jarak, border, posisi, dan layout.

2. Konsep yang perlu kamu kuasai

  • CSS rule terdiri dari selector dan declaration block.
  • Property menyebut apa yang diubah.
  • Value menyebut nilai property.

3. Sintaks / contoh dasar

body {
  background-color: #eef7ff;
}
h1 {
  color: #0b4f8a;
  text-align: center;
}
Perhatikan: CSS mengatur presentasi; HTML tetap menjadi struktur.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: rule pada materi CSS Introduction.
  2. Kerjakan poin: color pada materi CSS Introduction.
  3. Kerjakan poin: background pada materi CSS Introduction.
  4. Gabungkan CSS Introduction dengan kode lain dan buat hasil yang dapat dijalankan.
