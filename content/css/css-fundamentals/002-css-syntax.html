CSS · CSS Fundamentals

1. Apa itu CSS Syntax?

Sintaks CSS berbentuk selector { property: value; }. Kesalahan kecil seperti lupa titik dua atau kurawal dapat membuat aturan tidak bekerja.

2. Konsep yang perlu kamu kuasai

  • Selector diikuti declaration block.
  • Property dan value dipisahkan titik dua.
  • Setiap declaration biasanya diakhiri titik koma.

3. Sintaks / contoh dasar

p {
  color: blue;
  font-size: 18px;
}
Perhatikan: Cobalah menghapus salah satu titik koma atau kurawal untuk melihat bagaimana browser bereaksi.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: css rule pada materi CSS Syntax.
  2. Kerjakan poin: declaration pada materi CSS Syntax.
  3. Kerjakan poin: property/value pada materi CSS Syntax.
  4. Gabungkan CSS Syntax dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
