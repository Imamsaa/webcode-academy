CSS · CSS Advanced

1. Apa itu CSS Variables?

CSS custom properties memungkinkan nilai seperti warna utama, radius, atau spacing disimpan dan dipakai berulang kali.

2. Konsep yang perlu kamu kuasai

  • Nama custom property dimulai dengan --.
  • var(--nama) digunakan untuk membaca nilai.
  • :root sering digunakan untuk nilai global.

3. Sintaks / contoh dasar

:root {
  --primary: #04aa6d;
  --radius: 12px;
}
.card {
  color: var(--primary);
  border-radius: var(--radius);
}
Perhatikan: Dengan variable, perubahan tema tidak perlu dilakukan di banyak selector.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: custom property pada materi CSS Variables.
  2. Kerjakan poin: var pada materi CSS Variables.
  3. Kerjakan poin: root pada materi CSS Variables.
  4. Gabungkan CSS Variables dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
