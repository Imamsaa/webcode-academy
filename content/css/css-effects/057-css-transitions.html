CSS · CSS Effects

1. Apa itu CSS Transitions?

Transition membuat perubahan nilai CSS terjadi secara halus dalam waktu tertentu.

2. Konsep yang perlu kamu kuasai

  • transition menentukan property yang dianimasikan.
  • Durasi biasanya ditulis dalam s atau ms.
  • Timing function mengatur karakter perubahan.

3. Sintaks / contoh dasar

.button {
  background: #04aa6d;
  transition: background .2s ease, transform .2s ease;
}
.button:hover {
  transform: translateY(-2px);
}
Perhatikan: Transition cocok untuk feedback visual kecil seperti hover, fokus, atau perubahan state.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: transition pada materi CSS Transitions.
  2. Kerjakan poin: timing pada materi CSS Transitions.
  3. Kerjakan poin: property pada materi CSS Transitions.
  4. Gabungkan CSS Transitions dengan kode lain dan buat hasil yang dapat dijalankan.
