CSS · CSS Effects

1. Apa itu CSS Animations?

CSS animation menggunakan @keyframes untuk menentukan perubahan style dari satu tahap ke tahap lain.

2. Konsep yang perlu kamu kuasai

  • @keyframes menentukan tahapan.
  • animation menentukan cara animasi dijalankan.
  • Gunakan animasi secukupnya agar tidak mengganggu pengguna.

3. Sintaks / contoh dasar

@keyframes naik {
  from { transform: translateY(10px); }
  to { transform: translateY(0); }
}
.card { animation: naik .5s ease; }
Perhatikan: Bedakan transition dan animation: transition biasanya merespons perubahan state, sedangkan animation dapat berjalan sendiri.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: keyframes pada materi CSS Animations.
  2. Kerjakan poin: animation pada materi CSS Animations.
  3. Kerjakan poin: duration pada materi CSS Animations.
  4. Gabungkan CSS Animations dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
