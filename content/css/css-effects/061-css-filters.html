CSS · CSS Effects

1. Apa itu CSS Filters?

CSS Filters adalah konsep CSS yang perlu dipahami melalui hubungan selector, property, value, dan hasil visual.

2. Konsep yang perlu kamu kuasai

  • Pahami tujuan CSS Filters.
  • Pelajari property utama dan nilainya.
  • Ubah satu declaration lalu lihat hasilnya.
  • Gabungkan dengan layout atau typography setelah konsep dasar jelas.

3. Sintaks / contoh dasar

.card {
  padding: 16px;
  border: 1px solid #888;
}

/* Praktikkan: CSS Filters */
Perhatikan: Gunakan DevTools browser untuk melihat rule yang benar-benar diterapkan.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: css rule pada materi CSS Filters.
  2. Kerjakan poin: declaration pada materi CSS Filters.
  3. Kerjakan poin: property/value pada materi CSS Filters.
  4. Gabungkan CSS Filters dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
