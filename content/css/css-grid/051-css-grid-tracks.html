CSS · CSS Grid

1. Apa itu CSS Grid Tracks?

Grid menyusun elemen dalam dua dimensi: baris dan kolom.

2. Konsep yang perlu kamu kuasai

  • display:grid membuat container.
  • grid-template-columns membuat kolom.
  • gap memberi jarak.

3. Sintaks / contoh dasar

.grid { display: grid; grid-template-columns: repeat(2, 1fr); gap: 16px; }
Perhatikan: Mulai dengan 2 kolom lalu ubah menjadi 3 atau 4 untuk melihat efek.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: css rule pada materi CSS Grid Tracks.
  2. Kerjakan poin: declaration pada materi CSS Grid Tracks.
  3. Kerjakan poin: property/value pada materi CSS Grid Tracks.
  4. Gabungkan CSS Grid Tracks dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
