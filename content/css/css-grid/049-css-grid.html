CSS · CSS Grid

1. Apa itu CSS Grid?

CSS Grid adalah sistem layout dua dimensi yang mengatur baris dan kolom secara bersamaan.

2. Konsep yang perlu kamu kuasai

  • display:grid membuat grid container.
  • grid-template-columns menentukan kolom.
  • grid-template-rows menentukan baris.
  • gap mengatur jarak.

3. Sintaks / contoh dasar

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
Perhatikan: Grid cocok untuk gallery, dashboard, kartu produk, dan layout dengan baris/kolom yang jelas.

4. Bedah contoh

  1. Baca kode dari atas ke bawah.
  2. Tunjuk bagian yang menjadi struktur utama.
  3. Ubah satu bagian lalu tekan Run.
  4. Bandingkan hasil sebelum dan sesudah perubahan.

5. Kesalahan umum

  • Lupa titik dua, titik koma, atau kurawal.
  • Selector salah sehingga rule tidak mengenai elemen target.
  • Property ditulis tetapi value-nya tidak valid.

6. Latihan bertingkat

  1. Kerjakan poin: display grid pada materi CSS Grid.
  2. Kerjakan poin: grid template pada materi CSS Grid.
  3. Kerjakan poin: gap pada materi CSS Grid.
  4. Gabungkan CSS Grid dengan kode lain dan buat hasil yang dapat dijalankan.
🎯 Target: Jangan berhenti ketika kode “jalan”. Pastikan kamu bisa menjelaskan kenapa kode tersebut bekerja.
